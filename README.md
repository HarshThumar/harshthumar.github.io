# harshthumar.github.io

Personal engineering blog and formal protocol security research by **Harsh Thumar** (remote participant, IETF 127; independent researcher).

Live publication site: **[https://harshthumar.github.io/](https://harshthumar.github.io/)**

## Publications

1. **[Proving MCP Authorization: What We Modeled, What We Rediscovered, and Why Every Check Matters](/blog/2026-11-ietf127-mcp-authorization/)**
   - Machine-checked formal verification of Model Context Protocol authorization using Tamarin.
   - Comprehensive ablation lattice evaluating 9 models and 376 continuous lemma checks.
   - Raw MDX: `content/blog/2026-11-ietf127-mcp-authorization.mdx`

2. **[Agent Authorization for Indian Payments, Formally](/whitepaper/agent-payments-india/)**
   - Cryptographic mandate analysis for NPCI UPI Circle (OC 201 & OC 201-B for software delegates).
   - Machine-checked proofs in Tamarin (P10, P11, P12) and technical mapping to RBI FREE-AI, CERT-In, and DPDP Act 2023.
   - Raw MDX: `content/whitepaper/agent-payments-india.mdx`
